# Memory Card Game

A simple memory matching card game built with HTML, CSS, and JavaScript.

## How to Play

1. Open `index.html` in your browser
2. Click cards to flip them and reveal symbols
3. Find matching pairs of cards
4. Match all 8 pairs to win
5. Try to complete the game in fewer moves for a better score

## Features

- 16 cards with 8 emoji pairs
- Score tracking (10 points per match)
- Move counter
- New Game button
- Responsive design

## Running the Game

Simply open `index.html` in any modern web browser.
